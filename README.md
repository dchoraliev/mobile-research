# Research Chat App

A React Native mobile app with photo sharing, server-side OCR, and a full RAG pipeline backed by FastAPI, ChromaDB, and OpenRouter LLM.

---

## 1. Backend Setup

### 1.1 Create and activate the virtual environment

```bash
cd Backend
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux
```

Always activate the venv before installing packages or running the server. If you skip this step, packages install globally and the server will not find them.

### 1.2 Install dependencies

```bash
pip install -r requirements.txt
```

> The first time you run `ingest.py` or start the server, BGE-m3 (~570 MB) will be downloaded from HuggingFace and cached locally. Subsequent runs use the cache.

### 1.3 Install Tesseract OCR

Server-side OCR requires Tesseract to be installed on your machine.

**Windows:** Download and install from [github.com/UB-Mannheim/tesseract/wiki](https://github.com/UB-Mannheim/tesseract/wiki), then update the path in `main.py`:

```python
pytesseract.pytesseract.tesseract_cmd = r"C:\path\to\tesseract.exe"
```

**Mac/Linux:**
```bash
brew install tesseract      # macOS
sudo apt install tesseract-ocr  # Ubuntu/Debian
```

### 1.4 Create the `.env` file

Create a file called `.env` in `Backend/` with your OpenRouter API key:

```
OPENROUTER_API_KEY=sk-or-...
```

Get your key from [openrouter.ai/keys](https://openrouter.ai/keys).

> Never commit `.env` to Git. It is listed in `.gitignore`.

## 2. Knowledge Base Setup

### 2.1 Add documents to `docs/`

Drop `.txt` or `.pdf` files into `Backend/docs/`. These are the documents the RAG pipeline will search when users ask questions about photos.

Example documents to get started:
- A product manual as a `.txt` file
- A set of notes or reference sheets as `.txt` files
- Any PDF with searchable text

### 2.2 Ingest documents into the vector store

```bash
python ingest.py --source ./docs
```

This chunks each document into 500-character overlapping pieces, embeds them locally with BGE-m3, and stores them in `./vectorstore/`. Re-running is safe — the collection is deleted and rebuilt from scratch. Run this again whenever you add or update documents.

---

## 3. Running the Backend

```bash
uvicorn main:app --reload --port 8089
```

The server pre-loads the Chroma vector store on startup. If you see `WARNING: Vector store not found`, run `ingest.py` first.

## 4. Exposing the Backend to Your Phone (ngrok)

Since the app runs on a physical device, you need to tunnel your local server. Install ngrok from [ngrok.com/download](https://ngrok.com/download), then:

### 4.1 Link your ngrok account (one-time)

```bash
ngrok config add-authtoken YOUR_TOKEN_HERE
```

Get your token from [dashboard.ngrok.com](https://dashboard.ngrok.com/get-started/your-authtoken).

### 4.2 Start the tunnel (separate terminal)

```bash
ngrok http 8089
```

You will see a forwarding URL like:

```
https://your-subdomain.ngrok-free.app -> http://localhost:8089
```

Copy the subdomain for the next step. Note that ngrok generates a new subdomain each session on the free tier — update `config.js` each time.

## 5. Frontend Setup

### 5.1 Install dependencies

```bash
cd Frontend
npm install
```

### 5.2 Configure `config.js`

Open `Frontend/config.js` and paste your ngrok subdomain:

```js
const NGROK = "your-subdomain.ngrok-free.app";
const LOCAL_HTTP = `https://${NGROK}`;
const LOCAL_WS   = `wss://${NGROK}/ws`;
const USE_LOCAL  = true;
```

For production set `USE_LOCAL = false`. `PROD_HTTP` and `PROD_WS` already point to the Render deployment.

## 8. How the RAG Pipeline Works

1. User takes a photo — the image is sent to the backend `/ocr` endpoint where pytesseract extracts any text
2. A system message confirms how much text was detected
3. User types a question — this triggers a `POST /search` request
4. The backend combines the question and OCR text, embeds them with BGE-m3, and performs cosine similarity search against the Chroma vector store
5. The top matching chunks are formatted as XML context and sent to the LLM (via OpenRouter — Gemini 2.0 Flash Lite with GPT-4o mini as fallback)
6. The LLM answer is displayed in chat alongside the source documents it was derived from

To cancel the RAG flow and return to plain chat, tap the **✕ Clear** button that appears after taking a photo.

## 9. API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Health check |
| `WS` | `/ws` | WebSocket chat (broadcast to all clients) |
| `POST` | `/upload-photo` | Upload a photo, returns URL |
| `GET` | `/photos` | List all uploaded photos |
| `POST` | `/ocr` | Server-side OCR from base64 image |
| `POST` | `/ocr-from-stored` | Server-side OCR from an already-uploaded filename |
| `POST` | `/query` | Full RAG: semantic search + LLM answer |
| `POST` | `/search` | Alias for `/query` |

## 10. .gitignore

The following should be in your `.gitignore`:

```
venv/
__pycache__/
.env
vectorstore/
*.pyc
.expo/
```

To track the `docs/` folder without committing its contents:

```gitignore
# Ignore all .txt files except those in Backend/docs/
*.txt
!Backend/docs/*.txt
```

Place a `.gitkeep` file inside `docs/` so the empty folder is tracked:

```bash
type nul > Backend/docs/.gitkeep    # Windows
touch Backend/docs/.gitkeep         # Mac/Linux
```

## 11. Deploying to Render

1. Push your `Backend/` code to GitHub
2. Create a new **Web Service** on [render.com](https://render.com)
3. Set the build command to: `pip install -r requirements.txt`
4. Set the start command to: `uvicorn main:app --host 0.0.0.0 --port 8089`
5. Add `OPENROUTER_API_KEY` as an environment variable in the Render dashboard
6. Set `USE_LOCAL = false` in `config.js`

> Note: Render's free tier does not include GPU. BGE-m3 will run on CPU, which is slower for the first query after a cold start.
